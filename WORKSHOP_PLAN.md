# Workshop Plan

## Part 1: Introduction of Cloud Agents and Motivation

- Short participant introduction round, clarify individual backgrounds.
- Motivational speech.
- Why Cloud Agents?
- Why OpenHands?
- About self-correcting agents.
- About verification loops and reviews.
- Security and isolation.

## Part 2: Practical Exercise

- Setting up OpenHands with a fork of the workshop-repo.
- Apply your own change to the workshop-repo (with guidance, but free ideas welcome).
- Goal: self-correcting agent and observable results in practise, using OpenHands Cloud agents.

## Part 3: Individual Project and Advanced Setup

- Connection of subscriptions to OpenHands (e.g. Claude Code / Codex).
- Individual project setup and questions.
- Open end get to know / networking.
